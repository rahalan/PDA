- **Workstation safety:** do not run unbounded inference, builds or tests.

Use the existing external Edge session over CDP, never the integrated browser or a replacement browser profile.
- **Desktop-only interface:** preserve the existing desktop layout as the sole presentation. Do not add alternate layouts based on screen dimensions. Browser automation must not alter the shared external Edge tab's dimensions.
- **Repository hygiene:** preserve Git history and licensing. Keep secrets and generated build/test/runtime artifacts outside the repository. Do not touch external vault/state or commit/push without authorization. Report completed work as concise bullets.
